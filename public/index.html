Styles & paramètres URL

Events …

Les subs/resubs/gifts utilisent le moteur visuel harmonisé sur celui de /chat. Le moteur d’animation est commun à /feed et /chat et utilise exactement la même configuration runtime. Les rewards restent statiques. Les Bits utilisent un halo coloré pulsant sans orbes. Profil visuel validé par défaut : 60 FPS, traînée 350 px, orbe 7,5 px, glow 110 %, DPR 1×, halos pré-rendus, puis arrêt total après 25 secondes.

La durée des events est fixe : 25 secondes par défaut, indépendamment de la longueur du texte. Une fois ce délai atteint, le contour animé s’éteint pour éviter la fatigue visuelle, tout en laissant la carte statique si la vue est persistante.

Paramètres

?persist=1 aucun timer de disparition ?limit=8 messages visibles max ?base=2500 base message normal ?perWord=260 ms par mot normal ?minDuration=4000 ?maxDuration=12000 ?eventDuration=25000 durée fixe d’un event ?eventFps=60 FPS animation ?trailLength=350 longueur de traînée ?orbitDuration=4700 durée d’un tour en ms ?orbSize=7.5 taille de l’orbe ?glowIntensity=1.10 intensité du glow ?platform=twitch filtre plateforme ?events=chat,sub filtre types ?tint=0 désactive la teinte normale ?platformBadge=0 masque le badge plateforme ?animations=0 désactive toutes les animations
